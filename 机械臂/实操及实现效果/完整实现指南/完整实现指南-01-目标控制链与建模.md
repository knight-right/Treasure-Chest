# 1. 项目最终目标

机械臂运动学控制的最终目标不是“写出一个逆运动学函数”，而是建立一条从用户目标到机械臂实物动作的完整链路。

用户给出目标末端位姿：

$$
{}^{base}T_{tool,d}
$$

系统通过逆运动学计算出目标关节角：

$$
q_d = IK\left({}^{base}T_{tool,d}\right)
$$

再通过轨迹规划生成一系列随时间变化的关节命令：

$$
q_d(t),\quad \dot q_d(t),\quad \ddot q_d(t)
$$

最后由控制器驱动电机运动，并利用编码器反馈形成闭环。

完整目标可以概括为：

```text
目标末端位姿
    ↓
逆运动学
    ↓
目标关节角
    ↓
轨迹规划
    ↓
关节位置/速度/力矩控制
    ↓
电机与减速器
    ↓
机械臂实际运动
    ↓
编码器反馈
    ↓
当前关节角
    ↓
正运动学计算实际末端位姿
```

最终应该具备以下功能：

- 读取每个关节的实际角度；
- 计算当前末端位置与姿态；
- 输入一个目标末端位姿；
- 判断目标是否可达；
- 求出一组合理、连续且不超限的关节角；
- 规划平滑运动轨迹；
- 低速、安全地控制机械臂到达目标位置；
- 检测通信、编码器、驱动器和轨迹异常；
- 支持点到点运动和末端直线运动；
- 为后续速度控制、力控制、视觉抓取和自动规划打下基础。

# 2. 先理解完整控制链

运动学只负责描述机械臂“几何关系”，它本身不会让电机转动。

机械臂实物控制至少包括以下几层：

| 层级 | 功能 | 典型运行设备 |
|---|---|---|
| 任务层 | 抓取、搬运、示教、视觉目标 | PC/Linux |
| 规划层 | 目标解析、路径规划、轨迹规划 | PC/Linux/ROS 2 |
| 运动学层 | 正运动学、逆运动学、雅可比 | PC/Linux 或 MCU |
| 关节控制层 | 位置环、速度环、力矩环 | 驱动器/STM32 |
| 硬件执行层 | 电机、编码器、减速器、机械结构 | 实物机械臂 |
| 安全层 | 急停、限位、过流、超速、通信超时 | MCU/驱动器/硬件 |

运动学控制处于中间位置：

- 上游接收末端目标；
- 下游输出关节目标；
- 上游不关心电机细节；
- 下游不负责理解末端坐标。

这种分层非常重要，因为它决定了后续软件架构是否清晰。

# 3. 明确机械臂控制层级

在项目开始前，先确定你要实现哪一级控制。

## 3.1 关节空间位置控制

用户直接给出目标关节角：

$$
q_d =
\begin{bmatrix}
q_{1,d} & q_{2,d} & \cdots & q_{n,d}
\end{bmatrix}^T
$$

系统让每个关节运动到指定角度。

这是所有机械臂项目的第一步。

实现目标：

- 每个关节都能独立运动；
- 多关节能同步运动；
- 实际角度能跟踪目标角度；
- 运动过程不抖动、不冲击；
- 不触发软限位和硬限位。

## 3.2 末端点位控制

用户给出目标位置和姿态：

$$
p_d = [x_d, y_d, z_d]^T
$$

$$
R_d \in SO(3)
$$

组合为齐次变换矩阵：

$$
T_d =
\begin{bmatrix}
R_d & p_d\\
0 & 1
\end{bmatrix}
$$

系统通过逆运动学计算目标关节角，再执行关节空间轨迹。

适合：

- 从当前位置运动到某个抓取点；
- 点到点搬运；
- 示教点复现；
- 简单自动化任务。

## 3.3 笛卡尔空间轨迹控制

要求机械臂末端沿指定路径运动，例如：

- 直线；
- 圆弧；
- 曲线；
- 保持某个姿态移动；
- 边移动边旋转。

此时不能只在起点和终点进行逆运动学，而要对轨迹上的多个中间位姿进行逆解。

## 3.4 推荐实施顺序

```text
单电机开环测试
    ↓
单关节闭环控制
    ↓
多关节同步控制
    ↓
正运动学
    ↓
逆运动学
    ↓
关节空间点到点运动
    ↓
笛卡尔直线运动
    ↓
连续轨迹与高级控制
```

不要跳过前面的步骤直接做末端控制，否则一旦出错，很难判断问题来自：

- 电机；
- 编码器；
- 坐标系；
- 零位；
- 运动学；
- 轨迹规划；
- 通信；
- 控制器。

# 4. 机械参数与硬件信息收集

在写运动学程序之前，必须先建立机械臂参数表。

## 4.1 机械结构参数

需要记录：

- 机械臂自由度；
- 每个关节是旋转关节还是移动关节；
- 每个关节轴的空间方向；
- 连杆长度；
- 关节轴之间的偏距；
- 末端法兰长度；
- 夹爪或工具长度；
- 每个关节的机械零位；
- 各关节最大和最小角度；
- 自碰撞区域；
- 安装方向。

建议制作一张机械臂尺寸图，并明确所有尺寸从哪个坐标原点开始测量。

## 4.2 电机与减速器参数

每个关节需要记录：

| 参数 | 示例 |
|---|---|
| 电机类型 | 伺服、无刷、步进 |
| 编码器类型 | 增量式、单圈绝对值、多圈绝对值 |
| 编码器分辨率 | 17 bit、20 bit、4096 PPR |
| 减速器类型 | 谐波、行星、摆线 |
| 减速比 | 50:1、80:1、100:1 |
| 电机正方向 | 顺时针或逆时针 |
| 关节正方向 | 根据右手定则定义 |
| 驱动模式 | 位置、速度、力矩 |
| 通信接口 | CAN、FDCAN、EtherCAT、RS485 |
| 最大速度 | rad/s 或 rpm |
| 最大加速度 | rad/s² |
| 最大电流/力矩 | 安全限制 |

## 4.3 坐标与单位规范

必须统一：

- 角度：内部全部使用弧度；
- 长度：推荐使用米；
- 时间：秒；
- 速度：rad/s、m/s；
- 加速度：rad/s²、m/s²；
- 力矩：N·m；
- 矩阵：统一使用列向量还是行向量；
- 旋转：统一主动旋转或被动旋转约定；
- 坐标变换：明确 $ {}^AT_B $ 表示 B 坐标系相对于 A 坐标系。

推荐代码内部全部采用 SI 单位，只在界面显示时转换为度、毫米等。

# 5. 建立坐标系与符号规范

## 5.1 常见坐标系

机械臂通常包含：

```text
world：世界坐标系
base：机械臂基座坐标系
joint_i：第 i 个关节坐标系
flange：末端法兰坐标系
tool：工具中心点坐标系 TCP
camera：相机坐标系
object：目标物体坐标系
```

常见变换关系：

$$
{}^{world}T_{tool}
=
{}^{world}T_{base}
{}^{base}T_{flange}
{}^{flange}T_{tool}
$$

其中：

- $ {}^{world}T_{base} $：机械臂基座在世界中的位姿；
- $ {}^{base}T_{flange} $：运动学计算得到的法兰位姿；
- $ {}^{flange}T_{tool} $：工具相对法兰的固定变换。

## 5.2 右手定则

每个旋转关节的正方向必须按照右手定则定义：

- 右手大拇指指向关节轴正方向；
- 四指弯曲方向为关节正旋转方向。

实物电机正方向可能和运动学模型正方向相反，因此要设置方向因子：

$$
s_i \in \{-1,1\}
$$

## 5.3 坐标系错误的典型表现

- 机械臂仿真方向和实物相反；
- 关节 2 增大时，末端向下而不是向上；
- 正运动学位置大致正确，但姿态完全不对；
- 逆解在某些象限突然跳变；
- 末端直线在实物上变成弧线；
- 工具末端和法兰位置偏差固定。

# 6. 机械臂运动学建模

常见建模方法有：

1. 标准 DH 参数；
2. 改进 DH 参数；
3. POE（Product of Exponentials，指数积）；
4. URDF 关节树模型。

初次开发推荐：

- 理论推导和手写算法：使用标准 DH 或改进 DH；
- ROS 2 和工程集成：使用 URDF；
- 高级机器人算法：可进一步学习 POE。

## 6.1 标准 DH 参数

每个关节用四个参数描述：

| 参数 | 含义 |
|---|---|
| $a_i$ | 连杆长度 |
| $\alpha_i$ | 连杆扭转角 |
| $d_i$ | 连杆偏距 |
| $\theta_i$ | 关节角 |

标准 DH 变换矩阵：

$$
{}^{i-1}T_i =
\begin{bmatrix}
c_{\theta_i} &
-s_{\theta_i}c_{\alpha_i} &
s_{\theta_i}s_{\alpha_i} &
a_i c_{\theta_i}\\
s_{\theta_i} &
c_{\theta_i}c_{\alpha_i} &
-c_{\theta_i}s_{\alpha_i} &
a_i s_{\theta_i}\\
0 &
s_{\alpha_i} &
c_{\alpha_i} &
d_i\\
0 & 0 & 0 & 1
\end{bmatrix}
$$

其中：

$$
c_{\theta_i} = \cos\theta_i,\quad
s_{\theta_i} = \sin\theta_i
$$

对于旋转关节：

$$
\theta_i = q_i + \theta_{offset,i}
$$

对于移动关节：

$$
d_i = q_i + d_{offset,i}
$$

## 6.2 DH 建模步骤

1. 确定每个关节轴；
2. 将 $z_i$ 轴沿关节轴方向设置；
3. 确定相邻关节轴的公法线；
4. 将 $x_i$ 轴沿公法线设置；
5. 根据右手定则确定 $y_i$；
6. 填写 $a_i,\alpha_i,d_i,\theta_i$；
7. 绘制完整坐标系图；
8. 将零位姿态代入验证。

## 6.3 DH 参数表模板

| 关节 i | $a_i$ | $\alpha_i$ | $d_i$ | $\theta_i$ | 角度范围 |
|---|---:|---:|---:|---:|---:|
| 1 |  |  |  | $q_1+\theta_{01}$ |  |
| 2 |  |  |  | $q_2+\theta_{02}$ |  |
| 3 |  |  |  | $q_3+\theta_{03}$ |  |
| 4 |  |  |  | $q_4+\theta_{04}$ |  |
| 5 |  |  |  | $q_5+\theta_{05}$ |  |
| 6 |  |  |  | $q_6+\theta_{06}$ |  |

## 6.4 URDF 建模

URDF 用于描述：

- 连杆；
- 关节；
- 关节轴；
- 质量；
- 惯量；
- 碰撞模型；
- 可视化模型；
- 关节限位。

URDF 中最重要的是：

- `origin xyz/rpy`；
- `axis xyz`；
- `limit lower/upper/velocity/effort`；
- 父子 link 关系。

推荐先用简单几何体建立 URDF，验证运动方向后再加入 STL/DAE 模型。
