## 一、课程概览

### 课程目录

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-05-课程目录.png]]

课程分三个阶段：

## 二、从有刷到无刷

### 有刷直流电机

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-09-有刷直流电机原理.png]]

- 定子是固定的永磁体（图中红色 N 极、蓝色 S 极），转子是通电线圈。线圈在磁场里受安培力，产生转矩。
- 线圈转过半圈后，如果电流方向不变，受力方向就会反过来，电机只会来回摆。所以要靠**碳刷和换向器**在每半圈把线圈里的电流方向换一次，让转矩方向始终不变。
- 缺点：碳刷和换向器一直摩擦接触，噪声大，碳刷会磨损，寿命短，还会产生电火花。

### 无刷电机

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-10-无刷电机实物.png]]

- 无刷电机把结构反过来：**线圈放在定子上，永磁体放在转子上**。线圈不转，就不需要碳刷给它供电。
- 换向的工作改由驱动电路完成：控制器按转子位置，依次给三相线圈通电，让定子磁场一直“领着”转子磁场转。
- 截图里老师在实物上圈出的是中心的转轴和轴承、定子上的一组线圈，以及外圈。

### 六步换相

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-11-六步换相演示.png]]

- 左边是三相逆变器：每相上下两个开关（UH / UL、VH / VL、WH / WL），接成星形绕组。右边是电机剖面。
- 每一步只导通两相、一相悬空。图中这一步是 U 相上管和 V 相下管导通，电流从 U 进、V 出，W 悬空。
- 一个电周期分 6 步，每步定子磁场跳 60° 电角度，所以定子磁场只有 **6 个固定方向**。转子本身是连续转的，但它受到的转矩随着和定子磁场的夹角变化，换相时会突变，因此转矩脉动大。
- 这正是 FOC 要解决的问题：FOC 让定子磁场方向可以连续变化，始终和转子磁场保持 90°。

### 集中绕组与分布绕组

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-12-集中绕组与分布绕组.png]]

| | 集中绕组 | 分布绕组 |
| --- | --- | --- |
| 绕法 | 线圈绕在单个齿或少数几个齿上 | 同一相的线圈分散在多个槽里 |
| 优点 | 端部短、铜耗低，工艺简单，结构紧凑 | 磁场更接近正弦，谐波小，转矩平稳 |
| 缺点 | 谐波和转矩脉动比较明显 | 绕制复杂，端部长 |

一句话：集中绕组胜在紧凑好做，分布绕组胜在波形好、运行平稳。机器人关节电机多是扁平的外转子或大直径电机，常见集中绕组。

### PMSM 和 BLDC 的区别

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-16-PMSM与BLDC对比表.png]]

两者结构几乎一样：转子都是永磁体，定子都是三相绕组。真正的区别在**反电动势波形**，由此决定了用什么电流去驱动、用什么方法控制：

| | PMSM（永磁同步电机） | BLDC（无刷直流电机） |
| --- | --- | --- |
| 反电动势 | 正弦波 | 梯形波 |
| 相电流 | 正弦波 | 120° 导通的方波 |
| 常用控制 | FOC 矢量控制 | 六步换相 |
| 转矩脉动、低速平稳性 | 脉动小，低速平稳 | 脉动较明显，低速一般 |
| 控制复杂度 | 较高 | 较低 |
| 典型应用 | 伺服、机器人关节 | 风扇、水泵、电动工具 |

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-17-梯形与正弦反电动势.png]]

- BLDC 的反电动势是梯形波，平顶部分正好配合方波电流，但换相时有突变，转矩脉动大。
- PMSM 的反电动势是正弦波，配合正弦电流，转矩平稳。
- 反电动势是电机转起来时线圈切割磁场自己产生的电压，转速越高越大。

> **补充**：实际中两者的界限没那么严格。很多标着 BLDC 的电机（比如云台电机、航模电机）也可以用 FOC 驱动，只是反电动势不是标准正弦，效果会差一点。面试被问到时，先说“结构相同、反电动势波形不同”，再展开控制方式。

## 三、关节模组与减速器

### 关节模组的组成

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-02-关节模组爆炸图.png]]

一个机器人关节模组从输出端到尾部分三块：

- **减速箱**：前壳体、输出轴承、行星架、行星轮、行星滚针轴承、输出销、内齿圈。这是一个行星减速器。
- **无刷电机**：定子（铜线圈）、转子（永磁体）。转子直接带动太阳轮，作为减速器的输入。
- **控制器**：后壳体、驱动板、电子盖板，对外接直流电源和 CAN 总线。

也就是说，FOC 程序跑在尾部的控制器上，通过 CAN 接收上位机的指令。课程第三阶段做的就是这块控制器的软件。

### 三种减速器

课程用同一个输入转速 15 RPM 演示三种减速器，传动比和输出转速都可以在截图右侧看到。

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-13-行星减速器.png]]

**行星减速器**：内齿圈固定，太阳轮输入，行星架输出。行星轮绕太阳轮公转，同时自转。

- 例子：太阳轮 24 齿、内齿圈 72 齿，传动比 = 1 + 72 / 24 = 4，输出和输入同向。
- 特点：结构简单、效率高、成本低，单级传动比不大，有一定背隙。准直驱关节（比如四足机器人的关节）常用低减速比的行星减速器。

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-14-谐波减速器.png]]

**谐波减速器**：刚轮固定，椭圆形波发生器输入，柔轮输出。波发生器把柔轮撑成椭圆，柔轮和刚轮只在长轴两端啮合，波发生器转一圈，柔轮相对刚轮错开两个齿。

- 例子：刚轮 102 齿、柔轮 100 齿，齿差 2，传动比 = −100 / 2 = −50，负号表示输出和输入反向。
- 特点：单级减速比大、体积小、背隙小、精度高；柔轮会疲劳，刚度和抗冲击能力有限。协作机械臂的关节常用。

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-15-摆线针轮减速器.png]]

**摆线针轮减速器**：针齿圈固定，偏心轴输入，输出销 / 输出盘输出。偏心轴带着摆线轮公转，摆线轮和针齿啮合后低速反向自转，输出销把这个自转取出来。

- 例子：11 个针齿、摆线轮 10 齿，传动比 = −10 / (11 − 10) = −10。
- 特点：刚度高、抗冲击、承载大。工业机器人常用的 RV 减速器就是“行星 + 摆线针轮”两级结构。

> **补充**：名词表里也有减速器的词条，见 [[具身智能/基础知识/具身智能新手名词表/入门必知/03-硬件与本体部件|名词表 · 硬件与本体部件]]。优必选的机械岗面试问过 RV 减速器的优缺点，记在 [[嵌入式/面经/面经索引#还没单独建篇的线索|面经索引]]。

## 四、电机参数

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-18-电机参数本节目录.png]]

本节共 7 点：绕组接法、相 / 线电阻与电感、相电压与相电流、Kv 和 Kt、极对数与电角度、其余参数、参数和仿真模型的关系。下面整理了前 4 点。

### 1. 星形和三角形接法；相电阻与线电阻

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-19-星形与三角形相电阻.png]]

- **星形（Y）**：三相绕组的一端接在一起，形成中性点 N，另一端引出 U、V、W。
- **三角形（Δ）**：三相绕组首尾相连成一个闭合三角形，从三个连接点引出 U、V、W。
- 实际能测的只有两根引线之间的电阻，也就是**线电阻**；数据手册和 FOC 模型里要的是**相电阻**（一相绕组本身的电阻）。
  - 星形：两根引线之间串了两相，R线 = 2 × R相，所以 **R相 = R线 / 2**。
  - 三角形：两根引线之间是一相和另外两相串联后再并联，R线 = R相 ∥ 2R相 = 2/3 R相，所以 **R相 = 3/2 × R线**。

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-20-星形与三角形相电感.png]]

电感的换算关系和电阻一样：星形 L相 = L线 / 2，三角形 L相 = 3/2 × L线。（这是忽略绕组之间互感时的简化关系。）

### 2. 相电阻和相电感决定了什么

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-21-相电阻与相电感的作用.png]]

把一相绕组简化成电阻和电感串联：

$$u = R_s i + L_s \frac{di}{dt}$$

- **相电阻 Rs**：决定压降、铜耗和发热。
- **相电感 Ls**：决定电流建立有多快、PWM 引起的电流纹波有多大。电感大，电流变化慢，纹波小。
- 两者合起来决定电流对电压阶跃的响应：时间常数 **τ = Ls / Rs**，电流约经过 3τ～5τ 才稳定到 U / Rs。

这个式子的前提：三相对称、不考虑磁饱和、忽略互感、不考虑反电动势（低速或很短的时间内）。真实电机还有互感，电感随转子位置变化，还要考虑反电动势、PWM 和死区。

> **补充**：τ 和后面的电流环直接相关。电流环 PI 参数常用的整定方法就是拿 Ls、Rs 去“抵消”这个一阶环节，所以测准相电阻和相电感是调电流环的前提。

### 3. 相电压与相电流

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-22-星形接法电压电流.png]]

**星形**：线电流就是流过那一相的电流，**线电流 = 相电流**；线电压是两相电压的矢量差，**线电压 = √3 × 相电压**。

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-23-三角形接法电压电流.png]]

**三角形**：每相绕组直接接在两根引线之间，**线电压 = 相电压**；每根引线上的电流是两相电流的矢量差，**线电流 = √3 × 相电流**。

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-24-星形与三角形对比表.png]]

| | 星形（Y） | 三角形（Δ） |
| --- | --- | --- |
| 电压关系 | U线 = √3 U相 | U线 = U相 |
| 电流关系 | I线 = I相 | I线 = √3 I相 |
| 同一套绕组、同一线电压下 | 每相承受的电压低，电流小 | 每相承受整个线电压，电流大 |
| 表现 | 偏高电压、小电流，运行温和 | 偏低电压、大电流，输出能力强 |
| 线参数和相参数 | 线电阻、线电感大于相参数 | 线电阻、线电感小于相参数 |

### 4. Kv 和 Kt

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-25-Kv与Kt.png]]

| | Kv（转速常数） | Kt（转矩常数） |
| --- | --- | --- |
| 单位 | rpm/V | N·m/A |
| 含义 | 每伏电压对应多少转速 | 每安电流对应多少转矩 |
| 关系式 | n ≈ Kv · E（E 为反电动势） | Te = Kt · iq |
| 特点 | Kv 越大，同样电压下转得越快 | Kt 越大，同样电流下转矩越大 |

- 两者本质上都由电机的磁链决定，所以一般 **Kv 越大，Kt 越小**：高 Kv 电机偏速度，低 Kv 电机偏力矩。
- 关节电机要低速大转矩，通常选低 Kv（高 Kt）的电机，再配减速器。
- 式子里的 iq 就是 FOC 里 q 轴电流，所以 FOC 控制 iq 就等于直接控制转矩。

> **补充**：两者可以近似互相换算，Kt ≈ 60 / (2π · Kv) ≈ 9.55 / Kv（Kv 用 rpm/V，Kt 用 N·m/A）。不同厂家对 Kv 用线电压还是相电压、峰值还是有效值的定义不同，换算结果会差一个系数，用的时候要看手册的定义。Te = Kt · iq 在表贴式 PMSM（Ld = Lq）时成立。

## 五、FOC 预览

这几张图是课程开头展示的内容，原理在第 3 节以后才讲，先记下结论，学到时再回来补。

### 三环级联控制

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-08-FOC三环级联控制.png]]

信号从外到内传递：

- **位置环**：位置误差 θ_ref − θ → 输出速度参考 ω_ref。
- **速度环**：速度误差 ω_ref − ω → 输出 q 轴电流参考 iq_ref。
- **电流环**：电流误差 iq_ref − iq → 输出电压 Ud / Uq，经 SVPWM 变成 PWM 驱动电机。
- 三个反馈分别是编码器测的位置 θ、由位置算出的速度 ω、由相电流变换得到的 iq。
- 级联原则：**越靠内环，带宽越高、响应越快**。电流环最快，位置环最慢。调参也是从内往外调。

### SVPWM 马鞍波

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-03-SVPWM马鞍波.png]]

- 上图是三相正弦参考电压，下图是 SVPWM 实际输出的三相电压，波形像马鞍，所以叫马鞍波。
- SVPWM 只是给三相电压加了同一个偏置（共模分量）。三相加的是同一个值，相减之后抵消，所以**线电压不变**，电机感受到的还是正弦。
- 好处是把每相电压的峰值压低了，同样的母线电压能输出更高的线电压，**直流母线电压利用率更高**。

> **补充**：普通正弦 PWM 相电压幅值最高 Udc / 2，SVPWM 最高 Udc / √3，提高约 15%。

### 怎么从波形判断 FOC 对不对

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-04-FOC正确与错误波形.png]]

| 观察项 | 正确 | 错误 |
| --- | --- | --- |
| 三相电流 | 对称、平滑的正弦 | 畸变、不对称、有毛刺 |
| dq 轴电流 | Id ≈ 0，Iq 是平稳的直线 | Id、Iq 都在波动，互相串扰 |
| 转速 / 转矩 | 平滑上升后稳定 | 抖动，电机容易发热 |

以后实机调试时，用串口或上位机把这三组波形画出来对照这张图。常见的出错原因（如电角度零位不准、相序接错、电流采样偏置没校准）等学到实机部分再补。

### FOC 三环之后学什么

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-06-FOC三环与高级算法.png]]

![[嵌入式/电机控制与FOC/附件/PMSM电机基础与参数-07-FOC三环之后的进阶方向.png]]

三环是基础，往上分两个方向：

- **电机本体性能**：参数辨识（自动测出 Rs、Ld、Lq、磁链）、dq 解耦、前馈补偿、扰动观测器、弱磁控制（扩大高速范围）、过调制（进一步提高母线电压利用率）、死区补偿（修正逆变器非线性）。
- **机器人关节控制**：力矩控制、阻抗控制、柔顺控制、MIT 控制、重力补偿、末端抖动抑制、多关节协同、模型预测控制。

> **补充**：截图里把 MIT 控制写成“基于模型的自适应控制”，这和常见说法不同。机器人圈说的 MIT 模式一般指 MIT Mini Cheetah 关节驱动器的控制接口：上位机同时给目标位置、目标速度、Kp、Kd 和前馈力矩，驱动器算 τ = Kp(θ_des − θ) + Kd(ω_des − ω) + τ_ff，再交给电流环。本质上是一种关节级的阻抗控制。课程第 14 节会讲，到时以课程内容为准核对。
