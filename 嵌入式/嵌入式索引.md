# 嵌入式

[[首页|返回首页]]

这里放 MCU / STM32 这一层的内容：代码架构、RTOS、外设与驱动、通信总线、电机控制（含 FOC）。各主题按“基础知识、问答与疑问、实操及实现效果”分目录，子目录有内容时再新建。

## 已有主题

- [[嵌入式/软件架构/软件架构索引|软件架构]]：代码分层、解耦与驱动框架。

## 规划中的主题（有内容时再建目录）

| 主题目录        | 放什么                                                                                                      |
| ----------- | -------------------------------------------------------------------------------------------------------- |
| `电机控制与FOC/` | 电机原理（BLDC / PMSM）、Clarke / Park 变换、SVPWM、电流采样、电流环 / 速度环 / 位置环、编码器与无感观测器、SimpleFOC / ODrive 等开源方案、调参与波形记录 |
| `RTOS/`     | FreeRTOS / RT-Thread 的任务、队列、信号量、中断与调度                                                                    |
| `外设与驱动/`    | GPIO、定时器、ADC、DMA，以及具体器件（如 MPU6050、AHT21）的驱动笔记                                                            |
| `通信总线/`     | UART、IIC、SPI、CAN，以及 Modbus 等 MCU 侧协议                                                                     |
| `调试与工具/`    | CubeMX、Keil、J-Link、示波器与逻辑分析仪、sct 链接脚本                                                                    |

## 分类边界

- **FOC 属于嵌入式**：它是在 MCU 上实时运行的电机控制算法，依赖定时器 PWM、ADC 采样和中断，所以放在 `电机控制与FOC/`。
- 机械臂关节的运动学、轨迹规划、整臂控制放 [[机械臂/机械臂索引|机械臂]]；单个电机怎么转起来、怎么闭环放这里。
- C 语言语法、数据结构、GCC / GDB 等通用内容仍放 [[基础知识/基础知识索引|基础知识]]；只在 MCU 上才有意义的内容放这里。
- Jetson、相机等 Linux 侧硬件仍放 [[具身智能/具身智能索引|具身智能]] 的“硬件与感知”。
