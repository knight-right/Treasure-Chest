# 嵌入式

[[首页|返回首页]]

这里放 MCU / STM32 这一层的内容：代码架构、RTOS、外设与驱动、通信总线、电机控制（含 FOC）。各主题按“基础知识、问答与疑问、实操及实现效果”分目录，子目录有内容时再新建；面经是例外，分为题库和面试记录。

## 已有主题

- [[嵌入式/软件架构/软件架构索引|软件架构]]：代码分层、解耦与驱动框架。
- [[嵌入式/电机控制与FOC/电机控制与FOC索引|电机控制与FOC]]：电机原理、关节模组与减速器、电机参数、FOC 三环与 SVPWM。目前在跟树智电控的 FOC 课程，已整理到电机参数部分。
- [[嵌入式/面经/面经索引|面经]]：面试题题库和面试记录，只写面试时怎么答，原理链接到各主题的知识笔记。目前有几篇从网上整理的具身智能公司面试记录，题目已按知识点并入题库，参考答案还没有核对和练习。

## 分类边界

- **FOC 属于嵌入式**：它是在 MCU 上实时运行的电机控制算法，依赖定时器 PWM、ADC 采样和中断，所以放在 `电机控制与FOC/`。
- 机械臂关节的运动学、轨迹规划、整臂控制放 [[机械臂/机械臂索引|机械臂]]；单个电机怎么转起来、怎么闭环放这里。
- C 语言语法、数据结构、GCC / GDB 等通用内容仍放 [[基础知识/基础知识索引|基础知识]]；只在 MCU 上才有意义的内容放这里。
- Jetson、相机等 Linux 侧硬件仍放 [[具身智能/具身智能索引|具身智能]] 的“硬件与感知”。
- 嵌入式面试题和面试记录统一放 [[嵌入式/面经/面经索引|面经]]，包括 C 语言类的面试题；面经里只写口述版答案，原理仍放在对应主题。
