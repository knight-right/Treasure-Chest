## 题目

### 1. 电流和电压是怎么测的

- [ ] 能脱稿讲清楚
- **来源**：[[嵌入式/面经/面试记录/智元机器人-嵌入式-一面|智元机器人-嵌入式-一面]] 第 2 题，顺着比赛项目问的。
- **口述版答案**：
  - 电压：用电阻分压把母线电压降到 ADC 量程内，加 RC 滤波后进 ADC，按分压比换算回去。
  - 电流：最常见的是采样电阻加运放。电流流过毫欧级的采样电阻产生小电压，运放放大后进 ADC，电流 = (ADC 电压 − 零点偏置) ÷ (放大倍数 × 采样电阻)。需要隔离或电流很大时用霍尔电流传感器。
  - 电机驱动里要说清采样位置：下桥臂采样（成本低，只能在下管导通时采）、相线采样（任何时刻都能采，对运放共模抑制要求高）、母线单电阻采样（成本最低，要靠时序重构三相电流）。
  - 采样时刻要和 PWM 同步：用定时器触发 ADC，在下管导通的中间时刻采，避开开关瞬间的毛刺。
- **常见追问**：
  - 双电阻采样时第三相怎么来：三相电流和为零，用 $I_c = -I_a - I_b$ 算。
  - 电流有正有负，ADC 只能采正电压怎么办：运放输出加一个偏置（常见是 1.65 V），上电时电机不通电先采若干次求零点。
  - 为什么要用定时器触发而不是软件触发：软件触发的时刻不固定，会采到开关噪声，电流环也就不稳。
- **易错点**：
  - 只回答“用 ADC 采”，没说前端电路和换算关系。
  - 下桥臂采样时占空比接近 100% 会导致下管导通时间太短、采不准，要限制最大占空比。
- **深入阅读**：对应的知识笔记还没写，见 [[嵌入式/嵌入式学习路线|嵌入式学习路线]] 的阶段 4。

### 2. 知道哪些电机控制算法

- [ ] 能脱稿讲清楚
- **来源**：[[嵌入式/面经/面试记录/智元机器人-关节模组工程师-一面|智元机器人-关节模组工程师-一面]] 第 5 组题，前面先问了实习里接触到的电机知识。
- **口述版答案**：按电机类型讲。
  - 有刷直流电机：PWM 调压加 PID 闭环。
  - 无刷直流电机（BLDC）：六步换相，靠霍尔传感器或反电动势过零点判断换相时刻，控制简单但转矩有脉动。
  - 永磁同步电机（PMSM）：FOC，也叫矢量控制。把三相电流变换到跟着转子转的 dq 坐标系，d 轴管磁场、q 轴管转矩，两个量变成直流后各用一个 PI 控制，转矩平滑、效率高。机器人关节基本都用这个。
  - FOC 外面通常再套速度环和位置环，组成三环：位置环 → 速度环 → 电流环，越往里越快。
  - 还可以提一句：没有编码器时用无感算法估算转子位置，如滑模观测器、磁链观测器，低速用高频注入。
- **常见追问**：
  - FOC 的完整流程：采两相或三相电流 → Clarke → Park → $I_d$、$I_q$ 两个 PI → 反 Park → SVPWM → 逆变器。
  - 六步换相和 FOC 的区别：前者是方波电流、每 60° 电角度换一次相；后者是正弦电流、连续控制电流矢量方向。
  - 表贴式电机为什么让 $I_d = 0$：d 轴电流不产生转矩，只会发热，除非要弱磁升速。
- **易错点**：
  - 把 BLDC 和 PMSM、方波控制和 FOC 混着说。
  - 三环的内外顺序说反，最内层是电流环。
- **深入阅读**：[[具身智能/基础知识/具身智能新手名词表/入门必知/03-硬件与本体部件|名词表 · 硬件与本体部件]]（关节模组、减速器词条）；[[嵌入式/电机控制与FOC/基础知识/PMSM电机基础与参数#二、从有刷到无刷|PMSM电机基础与参数 · 从有刷到无刷]]（BLDC 与 PMSM、六步换相）；FOC 本身的知识笔记还没写。

### 3. Clarke 变换和 Park 变换的数学原理

- [ ] 能脱稿讲清楚
- **来源**：[[嵌入式/面经/面试记录/智元机器人-关节模组工程师-一面|智元机器人-关节模组工程师-一面]] 第 5 组题。原帖提到面试官要的是数学推导，只说出名字不够。
- **口述版答案**：
  - 目的：三相电流是三个互差 120° 的正弦量，直接控制很麻烦。两步变换把它们变成两个直流量，就能用普通 PI 控制。
  - Clarke 变换：三相静止坐标系 (a, b, c) → 两相静止坐标系 (α, β)。做法是把三相矢量投影到两根垂直的轴上，α 轴和 a 相重合，β 轴超前 90°。等幅值形式（系数 2/3）：

    $$I_\alpha = \tfrac{2}{3}\left(I_a - \tfrac{1}{2}I_b - \tfrac{1}{2}I_c\right),\quad I_\beta = \tfrac{2}{3}\cdot\tfrac{\sqrt{3}}{2}\left(I_b - I_c\right) = \tfrac{1}{\sqrt{3}}\left(I_b - I_c\right)$$

    代入 $I_a + I_b + I_c = 0$ 后化简成代码里常用的形式：

    $$I_\alpha = I_a,\quad I_\beta = \tfrac{1}{\sqrt{3}}\left(I_a + 2I_b\right)$$

  - Park 变换：两相静止坐标系 (α, β) → 跟转子同步旋转的坐标系 (d, q)。本质是把坐标系旋转一个电角度 θ，d 轴对准转子磁场方向：

    $$I_d = I_\alpha\cos\theta + I_\beta\sin\theta,\quad I_q = -I_\alpha\sin\theta + I_\beta\cos\theta$$

  - 变换后的效果：在 αβ 系里电流还是正弦量；到了 dq 系，坐标系跟着转子一起转，稳态时 $I_d$、$I_q$ 是直流量。
  - 控制量算出来后要变回去：反 Park 变换把 $V_d$、$V_q$ 变成 $V_\alpha$、$V_\beta$，再交给 SVPWM：

    $$V_\alpha = V_d\cos\theta - V_q\sin\theta,\quad V_\beta = V_d\sin\theta + V_q\cos\theta$$

- **常见追问**：
  - 系数 2/3 和 $\sqrt{2/3}$ 的区别：2/3 是等幅值变换，变换前后电流幅值相同，FOC 代码里常用；$\sqrt{2/3}$ 是等功率变换。
  - Clarke 里的 1/2 和 $\sqrt{3}/2$ 从哪来：b、c 两相分别在 120° 和 240° 方向，$\cos 120° = -1/2$，$\sin 120° = \sqrt{3}/2$，$\sin 240° = -\sqrt{3}/2$。
  - θ 是什么角度：电角度，等于机械角度乘极对数，还要加上编码器零位和电角度零位之间的偏移。
  - 为什么要变成直流量：PI 控制器跟踪直流量没有稳态误差，跟踪正弦量会有幅值和相位误差。
- **易错点**：
  - 把机械角度直接代进 Park 变换。
  - Park 变换的正负号写反，写完用 θ = 0 验证：此时应有 $I_d = I_\alpha$、$I_q = I_\beta$。
  - 讲不清两步各自的作用：Clarke 是三相变两相（降维），Park 是静止变旋转（把交流变直流）。
- **深入阅读**：对应的知识笔记还没写，见 [[嵌入式/嵌入式学习路线|嵌入式学习路线]] 的阶段 4。
