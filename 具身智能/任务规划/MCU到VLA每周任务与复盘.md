## 第一个月的四周安排

### 第 1 周：现有 WSL2 环境验收

- [ ] 在 PowerShell 记录 `wsl --version` 与 `wsl -l -v`，确认现有 Ubuntu 发行版使用 WSL2。
- [ ] 在 Ubuntu 内核对 24.04 版本，验收网络、Linux 项目目录与 Windows 文件交换；分别记录 WSLg 图形与 GPU 可用性。
- [ ] 建立项目目录，运行一个 Python 或 C++ 小程序，保存命令与输出。

**本周成果：** 一份实际环境记录，以及一次可重复的小程序运行。

### 第 2 周：ROS 2 可用

- [ ] 安装或核对 ROS 2 Jazzy，记录来源、版本和环境加载方法。
- [ ] 在两个终端运行 talker / listener，确认通信并保存输出。
- [ ] 修改一个消息或发布参数，说明结果变化；完成一次 Git 提交。

**本周成果：** ROS 2 通信记录与自己修改过的小示例。

### 第 3 周：图形或仿真可用

- [ ] 通过 WSLg 运行 RViz 或最小 MuJoCo 场景，记录显示与运行情况；CUDA 运算验证另行记录。
- [ ] 修改一个显示或场景参数，保存前后差异。
- [ ] 出现性能或渲染问题时，缩小场景并记录排查步骤；未解决项如实保留。

**本周成果：** 第一张运行截图或一段短演示，以及明确的已通过项。

### 第 4 周：重启后可以复现

- [ ] 重新进入 WSL2，按自己的记录重新运行 ROS 2 和已通过的图形 / 仿真示例。
- [ ] 补齐遗漏的命令、环境变量和依赖；在任务停止后用 `wsl --export` 导出所用发行版备份，并保存代码版本。
- [ ] 完成第一次月度复盘，确定第 2 月要使用的机械臂示例候选。

**本周成果：** 可复现的首月环境基线及下一步任务。
